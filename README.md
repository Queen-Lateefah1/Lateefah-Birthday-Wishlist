# Lateefah’s Birthday Wishlist
Birthday wishlist for Lateefah, with gift ideas and category filters


## View the site

After GitHub Pages is enabled, the site will be available at:

`https://Queen-Lateefah1.github.io/Lateefah's-birthday-wishlist/`

## Update the wishlist

Edit `index.html`. The gift ideas are in the `ITEMS` list near the bottom of the file. Save and commit your changes to publish the update.

## Privacy

The website is public. Review the wishlist before publishing.
